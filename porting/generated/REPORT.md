# Gish Android Port — Source Analysis

This directory contains files extracted from the original Gish JAR.

- source/: CFR-decompiled Java source
- original/: original JAR contents, including game resources
- imports.txt: Java imports used by the game
- j2me-apis.txt: detected Java ME API references
- cfr.log: decompiler output

This is source preparation, not yet a completed Android port.
